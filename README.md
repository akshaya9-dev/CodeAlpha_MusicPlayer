# 🎵 CodeAlpha Music Player

A modern and responsive web-based music player built using **HTML, CSS, and JavaScript** as part of my CodeAlpha Frontend Development Internship.

## ✨ Features

- ▶️ Play and pause songs
- ⏮ Previous song
- ⏭ Next song
- 🎵 Playlist selection
- 📊 Interactive progress bar
- ⏩ Seek through songs
- 🔊 Volume control
- 🔄 Automatic next-song playback
- 🖼️ Dynamic album artwork
- 🎶 Dynamic song title and artist information
- ✨ Active playlist indicator
- 📱 Responsive design
- ♿ Basic accessibility improvements
- 🌙 Modern dark glassmorphism interface
- 💫 Animated album artwork and equalizer effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
